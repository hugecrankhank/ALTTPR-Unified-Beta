# ALTTPR Unified Lite

Emulator + auto-tracker for older phones and tablets.

- Load your seed as a `.sfc` ROM file (you supply it; nothing is uploaded).
- Press **Make available offline** once and it works in airplane mode. On iPhone/iPad,
  add it to your Home Screen too, so iOS keeps the offline copy.
- Want seed generation or the full tracker? Use [ALTTPR Unified](https://github.com/hugecrankhank/ALTTPR-Unified).

Built on the Hutch tracker (github.com/hutchch/ALTTPR-Tracker).
